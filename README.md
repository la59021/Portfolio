CS 122 Portfolio - Battle Tic-Tac-toe
=====================================
Battle Tic-Tac-Toe
------------------
Is normal tic-tac-toe but players select classes with skills, and are able to pick their mark.

Compilation Instructions
------------------------
To compile and run a full game use ```make 1```

To compile and run a normal game use ```make 2```

To compile and run a battle game use ```make 3```

To compile and run a normal board test use ```make 4```

To compile and run a battle board test use ```make 5```
